# 许可证选择：MIT

| 许可证 | 商业使用/闭源再分发 | 主要要求 |
|---|---|---|
| MIT | 允许 | 保留版权及许可声明；条款简短 |
| Apache-2.0 | 允许 | 保留许可及适用声明、标注修改；有明确专利授权和终止条款 |
| GPL-3.0 | 允许商业使用；受覆盖衍生作品分发时须遵守源码开放要求 | 分发时提供对应源码，并采用兼容的 GPL 授权 |
| AGPL-3.0 | 允许商业使用；另涉及网络交互场景 | 修改后的程序供用户通过网络交互时，须向这些用户提供获取对应源码的机会 |

如果主要目的是简历展示与方便他人学习复用，可优先考虑 MIT；若重视明确的专利授权，可考虑 Apache-2.0。如果要求受覆盖的衍生版本也开放源码，可考虑 GPL/AGPL。
这些许可证均不意味着“禁止商业使用”，也不等同于商标授权。

维护者于 2026-10-19 选择 MIT，版权署名为 Alesia0411，完整条款见根目录 LICENSE。以下对照用于说明备选方案，不替代实际许可条款。
